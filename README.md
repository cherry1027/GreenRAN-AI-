# GreenRAN AI — Traffic-Aware 6G Resource Controller

GreenRAN AI is a small independent research prototype demonstrating synthetic, traffic-aware resource control for a simulated 6G RAN node.

**Live demo:**  
https://greenran-ai-6g-controller.charanvaranasi44.workers.dev

## Features

- Simulated 24-hour cellular traffic curve
- Live synthetic RAN metrics
- AI Control ON/OFF switch
- PPO-style CPU core and frequency adaptation
- Resource-control pipeline visualization
- AI decision log
- Static vs adaptive resource-allocation benchmark
- Traffic, CPU allocation, power, and energy charts
- Illustrative energy savings with zero simulated service interruptions
- Responsive two-page telecom engineering dashboard

## Pages

1. **Live RAN Node** — interactive traffic and resource-control simulation
2. **Green 6G Benchmark** — static allocation versus PPO-style adaptive allocation
